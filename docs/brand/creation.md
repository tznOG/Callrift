# Criação dos assets

A versão atual do banner acrescenta **VPN para Discord**. Consulte o [prompt dessa edição](descriptor-edit.md). Os prompts abaixo registram a identidade inicial.

Ferramenta: `image_gen.imagegen` (geração de imagens integrada). O banner foi gerado com o PNG do mascote como referência. Os PNGs estão salvos no projeto; os arquivos ICO e a miniatura são exportações mecânicas feitas com System.Drawing.

## Mascote — `assets/brand/callrift-logo.png`

```text
Use case: logo-brand. Asset type: final production app icon / mascot logo for a Windows desktop application named Callrift. Create ONE original, exceptionally polished, simple flat vector-style mascot symbol only, NO letters and NO wordmark. The application routes Discord voice and screen-sharing traffic through a separate VPN while games keep their usual internet route; the mark should suggest a friendly communication portal. Style direction: the friendly, rounded, instantly recognizable gaming community branding language associated with Discord, but design an ORIGINAL silhouette rather than reproducing Clyde or a game controller. Main idea: a compact rounded circular chat-portal creature, with a C-shaped ring opening gently toward the upper right, two expressive dark oval eyes in a white face, a subtle small chat-tail at the lower left, and ONE short mint route accent at the opening. Keep the silhouette strong and memorable with only a handful of clean shapes, visually balanced, substantial thickness, smooth curves, no thin details. Primary vivid violet #8152EB / #9566FF, white face, dark navy #14151C eyes, optional single mint #64D8AD accent. This must work legibly at 24px as a Windows tray icon and as a GitHub avatar. Center the single mark in a square canvas, symbol fills about 78 percent of canvas with clear equal margins. True TRANSPARENT background around the mark, preserve alpha. Flat color fills only. No text, no watermark, no presentation board, no multiple versions, no mockup, no surface, no shadows, no 3D, no glossy gradients.
```

## Banner — `assets/brand/callrift-banner.png`

```text
Use case: logo-brand. Asset type: GitHub repository banner and social preview, wide landscape 2:1 composition, final raster PNG. Use the referenced Callrift mascot logo as the EXACT identity reference: preserve its friendly C-shaped violet communication portal, white face, dark oval eyes and mint accent. Design a tasteful minimal launch banner for Callrift, a native Windows app for Discord-only VPN routing and local activity presence. Background solid near-black navy #101116 with extremely subtle understated violet portal/routing arcs in the far corners, no busy decoration. Place the same mascot cleanly on the left at moderate scale, with ample negative space. On the right, typeset a bold, beautifully spaced modern rounded geometric wordmark, EXACT text 'Callrift' in white, C uppercase, rest lowercase. Beneath it, smaller quiet gray text EXACT 'Sua call. Outra rota.' Then a tiny restrained feature line EXACT 'WINDOWS  /  WIREGUARD  /  PRESENCE'. Palette: violet #8152EB, white, near-black, one small mint accent. Brand aesthetic: polished independent gaming utility, friendly and confident, crisp edges and legible typography, professional open-source software cover. The mascot must be consistent with the referenced image, do not draw Discord Clyde, do not include Discord's wordmark, do not add a fake app screenshot, feature badges, buttons, claims, charts, stars or downloads counters. Keep everything inside the central safe area with generous 80px padding, clean 1280x640-equivalent wide framing. No 3D, no mockup, no watermark.
```
