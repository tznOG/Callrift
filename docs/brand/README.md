# Identidade Callrift

**Callrift** junta *call* e *rift*: uma passagem para outra rota de conexão. A descrição fixa é **VPN para Discord**, exibida abaixo do nome. A assinatura é **Sua call. Outra rota.** Presence é o nome do módulo de atividades.

O mascote combina um portal em C com um balão de conversa. Formas arredondadas, rosto claro e um detalhe verde aproximam a identidade do universo de comunidades e jogos. A silhueta é própria do Callrift.

| Arquivo | Uso |
| --- | --- |
| `assets/brand/callrift-logo.png` | Mascote com transparência; avatar e material de divulgação |
| `assets/brand/callrift-banner.png` | Capa do README e divulgação |
| `assets/brand/callrift-mark-128.png` | Miniatura embarcada no app |
| `assets/callrift.ico` | Executável, janela e bandeja; 16 a 256 px |

As miniaturas e o ICO são exportados por `scripts/Create-Icon.ps1`. O app usa apenas a miniatura e o ícone; o banner não é carregado na interface.

| Cor | Hex |
| --- | --- |
| Violeta | `#8152EB` |
| Violeta claro | `#9566FF` |
| Fundo | `#101116` |
| Verde | `#64D8AD` |
| Branco | `#FFFFFF` |

Mantenha a proporção do mascote, sua transparência e espaço livre ao redor. Evite fundos com pouco contraste. O nome não passou por pesquisa de registro de marca.

O [registro de criação](creation.md) reúne os prompts dos dois PNGs originais.
