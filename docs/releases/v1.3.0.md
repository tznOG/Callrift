# Callrift 1.3.0 — Instalador e avisos de atualização

Agora você pode instalar o Callrift no Windows ou continuar usando a versão portátil. Ao abrir, o app também avisa quando houver uma nova versão estável publicada neste repositório.

## Novidades

- Instalador por usuário, com atalho no menu Iniciar, atalho opcional na área de trabalho e desinstalação pelo Windows.
- Atualização da instalação no mesmo local, preservando perfis, favoritos e preferências.
- Consulta de novas versões ao abrir, aviso com opção de adiar e banner com acesso ao download.
- Verificação manual e opção de desativar a consulta automática em Configurações → Atualizações.
- Download correspondente à sua cópia: instalador para a versão instalada e ZIP para a portátil.
- Falhas de rede, rascunhos, pré-lançamentos e uploads incompletos não bloqueiam o aplicativo.

## Qual arquivo baixar?

| Arquivo | Uso |
| --- | --- |
| **Callrift-Setup-1.3.0.exe** | Instalar ou atualizar no Windows; opção recomendada para uso comum |
| **Callrift-1.3.0-Windows-x64.zip** | Usar sem instalar; extraia a pasta inteira e abra Callrift.exe |
| **SHA256SUMS.txt** | Conferir a integridade dos dois downloads |

Requer Windows 10/11 x64, .NET Framework 4.8, Discord desktop e um arquivo WireGuard da Proton VPN. Os arquivos **Source code** contêm os fontes, não o aplicativo pronto. O instalador e os binários ainda não têm assinatura de editor.

## Atualizar com seus dados preservados

Use **Sair** na bandeja antes de executar o instalador ou substituir a pasta portátil. Os dados continuam em `%LOCALAPPDATA%\DiscordVPN`. Desinstalar também preserva esses dados. Se migrar da portátil para a instalada e usava inicialização com Windows, desative na cópia antiga e reative na nova.

Esta é a primeira versão com avisos de atualização. Quem usa 1.2.0 ou anterior deve baixar a 1.3.0 manualmente uma vez. Os avisos seguintes dependem de novas releases estáveis publicadas em `tznOG/Callrift`. O download abre no navegador; a instalação depende da sua escolha.

## Limites de conexão

O Discord usa o túnel; os demais aplicativos usam saída direta, mas podem passar pela classificação local do adaptador. O DNS do Windows é preservado. Não há kill switch ou reconexão automática. O comparador mede resposta HTTPS, não ping de jogos. O Presence depende da detecção de atividades do Discord.
