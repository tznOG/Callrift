# Callrift 1.2.0 — VPN para Discord

O Callrift reúne uma conexão WireGuard dedicada aos processos do Discord e o Presence, módulo local de atividades. A interface é nativa para Windows, com temas claro e escuro.

## Nesta versão

- Descrição **VPN para Discord** no app e na apresentação do projeto.
- Nome e identidade Callrift aplicados à janela, executável e bandeja.
- Importação de perfis `.conf` da Proton VPN, conexão verificada pelo túnel e controle pela bandeja.
- Pedido de autorização para reiniciar um Discord já aberto após conectar.
- Comparação de perfis por resposta HTTPS, com mediana em milissegundos e melhor resultado da rodada.
- Presence com busca, favoritos, seleção de executável, várias atividades e cache local.
- Inicialização com Windows e opção de abrir o Discord depois de verificar a VPN.

## Baixar e abrir

Baixe **Callrift-1.2.0-Windows-x64.zip**, extraia a pasta inteira e abra **Callrift.exe**. Não mova somente o executável. Requer Windows 10/11 x64, .NET Framework 4.8, Discord desktop e um perfil WireGuard da sua conta Proton VPN.

Os arquivos chamados **Source code** são o código-fonte; para usar o app pronto, escolha o ZIP **Windows-x64**. O pacote ainda não tem assinatura de editor comercial.

Para conferir o download no PowerShell:

```powershell
Get-FileHash .\Callrift-1.2.0-Windows-x64.zip -Algorithm SHA256
```

Compare o resultado com **SHA256SUMS.txt** anexado a esta release.

## Quem já usava Discord VPN

Saia da versão antiga pelo menu da bandeja. Os perfis, favoritos e configurações continuam disponíveis. Se usava inicialização com Windows, desative a opção na versão antiga e reative no Callrift para atualizar o caminho do executável.

## Limites conhecidos

Os demais aplicativos usam saída direta, mas seu tráfego pode passar pela classificação local do adaptador virtual. Não há promessa de impacto zero. Esta versão preserva o DNS do Windows e não oferece kill switch ou reconexão automática. O comparador mede resposta HTTPS, não ping do Discord ou de jogos. Presence depende da detecção do Discord e não garante recompensas.

O pacote inclui avisos e licenças dos componentes, além do arquivo-fonte da versão distribuída do sing-box. Consulte o README e o guia de uso no repositório para detalhes.
